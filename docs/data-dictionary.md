# Analytical Data Dictionary

## `marts.fact_deliveries`

Grain: one row per shipment from the latest completed immutable source batch, including records
with quality exceptions.

| Column | Type / role | Definition |
|---|---|---|
| `shipment_id` | Natural key | Unique shipment identifier and fact grain |
| `order_id` | Degenerate dimension | Source order identifier used for traceability |
| `customer_key` | Foreign key | Hashed key to `dim_customer`; null for unmatched orders |
| `carrier_key` | Foreign key | Hashed key to `dim_carrier`, including the unknown member |
| `distribution_center_key` | Foreign key | Hashed key to `dim_distribution_center` |
| `location_key` | Foreign key | Hashed key to `dim_location` |
| `service_type_key` | Foreign key | Hashed key to `dim_service_type` |
| `order_date_key` | Date key | `YYYYMMDD` role-playing key from `order_at` |
| `shipped_date_key` | Date key | `YYYYMMDD` role-playing key from `shipped_at` |
| `promised_delivery_date_key` | Date key | `YYYYMMDD` primary reporting key from the promised date |
| `delivered_date_key` | Date key | `YYYYMMDD` role-playing key; null for undelivered rows |
| `order_at` | Timestamp | Order creation timestamp |
| `shipped_at` | Timestamp | Shipment dispatch timestamp |
| `promised_delivery_at` | Timestamp | Customer-facing delivery promise |
| `delivered_at` | Timestamp | Actual delivery timestamp, when available |
| `delivery_status` | Attribute | Normalized `in_transit` or `delivered` status |
| `delivery_attempts` | Additive measure | Number of recorded delivery attempts |
| `quantity` | Additive measure | Ordered units inherited from the matched order |
| `weight_kg` | Additive measure | Shipment weight in kilograms |
| `freight_amount` | Additive measure | Synthetic freight amount in BRL |
| `event_count` | Additive measure | Count of staged events associated with the shipment |
| `exception_count` | Additive measure | Count of `delivery_exception` events |
| `failure_reason` | Attribute | Recorded exception reason summarized at shipment grain |
| `order_to_ship_hours` | Duration | Hours from order creation to dispatch |
| `ship_to_delivery_hours` | Duration | Hours from dispatch to actual delivery |
| `delivery_delay_days` | Duration | Actual delivery minus promised delivery, in fractional days |
| `is_on_time` | KPI flag | True when eligible actual delivery is no later than promise |
| `is_valid_for_sla` | Governance flag | True only when every SLA eligibility rule passes |
| `is_orphan_order` | Quality flag | Shipment cannot be matched to a staged order |
| `is_unknown_carrier` | Quality flag | Carrier is outside the governed source domain |
| `is_delivery_before_shipment` | Quality flag | Actual delivery occurs before dispatch |
| `is_delivered_without_timestamp` | Quality flag | Delivered status has no delivery timestamp |
| `has_invalid_order` | Quality flag | Matched order is invalid, or no valid order exists |
| `source_batch_id` | Lineage | Deterministic source batch identifier |
| `_load_id` | Lineage | Immutable ingestion load identifier derived from the manifest hash |
| `_ingested_at` | Lineage | Raw ingestion timestamp |

## Dimensions

### `marts.dim_date`

Grain: one calendar day covering the operational date range.

| Column | Definition |
|---|---|
| `date_key` | Integer `YYYYMMDD` primary key |
| `date_day` | Calendar date |
| `year`, `quarter`, `month_number` | Calendar hierarchy attributes |
| `month_name`, `day_name` | English abbreviated labels generated by PostgreSQL |
| `iso_day_of_week` | ISO weekday number, Monday = 1 |
| `is_weekend` | Saturday/Sunday flag |

### `marts.dim_carrier`

Grain: one normalized carrier value.

| Column | Definition |
|---|---|
| `carrier_key` | Deterministic hashed key |
| `carrier_name` | Synthetic carrier name |
| `is_unknown_carrier` | Governed unknown-member flag |

### `marts.dim_customer`

Grain: one synthetic customer identifier. Contains no real personal information.

| Column | Definition |
|---|---|
| `customer_key` | Deterministic hashed key |
| `customer_id` | Synthetic customer identifier |

### `marts.dim_distribution_center`

Grain: one distribution center.

| Column | Definition |
|---|---|
| `distribution_center_key` | Deterministic hashed key |
| `distribution_center_id` | Synthetic center identifier |

### `marts.dim_location`

Grain: one destination region.

| Column | Definition |
|---|---|
| `location_key` | Deterministic hashed key |
| `destination_region` | Governed region label |

### `marts.dim_service_type`

Grain: one delivery service type.

| Column | Definition |
|---|---|
| `service_type_key` | Deterministic hashed key |
| `service_type` | `express`, `standard`, or `economy` |

## Staging and intermediate models

| Model | Grain | Main responsibility |
|---|---|---|
| `stg_orders` | One deduplicated order | Type conversion, domain checks, duplicate ranking, and order validity |
| `stg_shipments` | One shipment | Type conversion, status normalization, timeline and carrier checks |
| `stg_delivery_events` | One event | JSON preservation, typed event fields, and controlled event domain |
| `int_deliveries_enriched` | One shipment | Order join, event aggregation, lifecycle durations, SLA logic, and quality flags |

The source column contracts and raw metadata are documented separately in
[data-contracts.md](data-contracts.md).
